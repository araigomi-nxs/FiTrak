# FiTrak

FiTrak is a modern **fitness tracker app** built with **native Java Swing**.  
It helps users **track exercise activities**, tally results, and leverage **pre-added exercise calculations** for a seamless fitness monitoring experience.

> 📌 This project was developed as a **Final Project for School** – showcasing applied Object-Oriented Programming, UI design, and database integration.

---

## 📂 Features
- 📊 **Activity Tracking** – Log and monitor your workouts and exercises.
- 🔢 **Pre-added Calculations** – Built-in formulas for calories, reps, sets, and more.
- 🎨 **Modern Java Swing UI** – Clean, responsive design for an intuitive user experience.
- 🌐 **Dual Database Support**:
  - **Supabase (Online)** – Master data list for cloud synchronization.
  - **SQLite (Offline)** – Local storage for offline usage and quick access.
  - **Syncing Algorithm**- Keeps the dual multibase in sync for updated accounts and activities for multiple devices

---

## 🛠️ Tech Stack

- **Backend/Logic**: Java 
- **Frontend/UI**: 
    - Java Swing (native desktop design)
    - [FlatLaf](https://www.formdev.com/flatlaf/)
    - MigLayout  
    - [Date/Time Picker: swing-datetime-picker (io.github.dj-raven)  ](https://github.com/DJ-Raven/swing-datetime-picker)
- **Databases**:
  - Supabase (PostgreSQL-based cloud DB)
  - SQLite (local lightweight DB) JDBC 
- **Networking**: OkHttp  
- **JSON Handling**: Gson & Jackson  
- ~~**Connection Pooling**: HikariCP~~ -Removed
- **Build Tool**: Maven
